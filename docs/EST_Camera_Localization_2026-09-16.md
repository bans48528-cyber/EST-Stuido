# EST Studio 摄像头界面本地化

版本：2.8.45

## 覆盖范围

支持软件当前提供的五种语言：简体中文、繁体中文、英语、巴西葡萄牙语、俄语。

- 菜单栏摄像头入口的提示文字与无障碍名称。
- 独立窗口标题、标题栏关闭按钮、摄像头选择与默认设备名称。
- 开始、停止、模型加载、初始化、预热、等待和未开启状态。
- 左右手、人体、面部开关及其无障碍名称。
- 全部已实现的手势、人体姿态、面部动作，以及未检测、关闭状态。
- 帧率与耗时标签、EST 发送状态、暂停、等待程序、固件能力不足等提示。
- 摄像头权限、设备断开、设备占用、模型失败、识别失败、发送失败的提示。
- 软件发出的摄像头权限拒绝弹窗。
- 主页摄像头指南的文字、打开按钮、图片说明及本地化示例截图。

摄像头驱动提供的设备型号保留原名。操作系统自己的授权界面语言由操作系统决定。
本次未对摄像头以外的全部软件界面做翻译完整性承诺。

## 实现

`src/common/est-camera-messages.json` 包含每种语言对应的 75 项窗口与识别结果文案。
`src/renderer/est-vision/guide-messages.json` 补充原先回退到英文或简体中文的摄像头指南。
这些词条合并进入现有 `getEstText`，不另建界面语言选择器。

错误与发送状态保存翻译键，模型进度保存阶段和模型类型。切换语言后，已有状态也会重新翻译。
识别模块内部标签、目标类别、HID 数据和发送逻辑保持不变。

主窗口把当前语言传给独立窗口；窗口挂载后主动同步最新语言，避免打开期间切换语言造成旧值残留。
后续切换不重启模型、不申请新的发送会话，也不改变开关选择。

长文字允许换行，摄像头窗口保留纵向滚动；结果列和开关区域适配较长的葡萄牙语、俄语文字。

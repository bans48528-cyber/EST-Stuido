# NEW AI 外设更新

连接 NEW AI 后，软件比较外设上报的 `version`（外设当前版本）与 `SoftwareVersion` / `Softwareversion`（主机内置镜像版本）。版本不同则提示用户更新；取消后，同一次连接、相同外设组合不重复提示。程序运行或下载、主机升级期间延后提醒。主机版本不匹配时先处理主机更新。

用户也可从连接面板右上角「… → 设备信息 → 外设更新」手动打开。点击一次「更新外设」即可开始，无额外勾选。正在运行程序时需先停止程序。

## 支持范围

| 外设 | 0x32 目标 ID | 主机镜像 |
| --- | --- | --- |
| 大电机 | A1 | app/motor.bin |
| 小 / 中电机 | A6 | app/small_motor.bin |
| 颜色 | A2 | app/color.bin |
| 灰度 | A9 | app/gray.bin |
| 灰度 V2 | B0 | app/grayv2.bin |

只更新已识别且回报两个有效版本的上述外设。NFC、红外、触碰、超声波、摄像头、电磁外设不加入此更新命令；现有软件资源没有为它们全部提供可用镜像及版本闭环。未知端口不允许猜测类型刷写。

## 通信与结果

- 沿用原版 `5A 97 98 08 32 [A–H 八字节目标 ID] checksum A5`。无须更新的端口填 FF。支持 USB 和蓝牙。
- 镜像由主机从自身文件系统读取并写入外设；不发送主机格式化或程序下载命令。
- 确认时记录连接代次、端口、类型和版本；发命令前再次读取状态，设备或外设变化时请用户重新打开。
- 命令只发送一次，不按超时自动重发。发送成功和普通 ACK 都不视为升级成功。
- 三次连续的新状态报告中，所有目标端口的类型、当前版本及主机要求版本均匹配，才显示更新完成。界面显示已确认外设数量，不虚构刷写百分比。
- 超过 180 秒仍未确认、写入失败或连接断开，显示未确认 / 连接错误。不会宣告成功，也不自动再次刷写。
- 更新期间暂停程序下载、设备切换和主动断开；完成或失败后恢复。未修改下位机。

## 验证

```text
node scripts/test-new-ai-peripherals.js
node scripts/check-new-ai-peripheral-electron.js
```

第一项使用模拟通信验证五种外设、多端口、USB / 蓝牙、版本核对、断线、超时、写入失败、热插拔和互斥。第二项使用隔离配置和模拟 IPC 运行真实界面，验证自动提醒、手动入口、取消去重、成功 / 失败、重连提醒和五种语言布局。两项均不连接真实硬件。

本次尚未对真实的旧版本外设进行刷写验收；需使用版本不匹配的外设核对主机实际升级及升级后的版本回报。

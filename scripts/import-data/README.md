# 积木导入所需的最小输入

本目录保存 Spark AI 1.1.9 与 NEW AI 2.2.29 已核对积木清单、实际使用的 SVG，以及 NEW AI 生成器必需的原始核心与辅助函数。输入来自此前用户提供的 2026-10-23 研究提取包，仅保留导入脚本读取的字段。Spark AI 1.1.10 的新增积木由 `../spark-ai-1.1.10-delta.json` 叠加。

两个积木导入脚本默认读取本目录；也可通过第一个参数指定同结构的外部提取目录，第二个参数指定图标目录。编译器脚本默认校验 `resources/` 中现有编译器并保留仓库内的样例；更新时，第一个参数为新编译器文件，第二个参数为可选的样例目录。

原始生成器中的版权与 Apache-2.0 声明保留。清理工作区的 `artifacts/` 不影响积木再生成、编译、测试或打包。
